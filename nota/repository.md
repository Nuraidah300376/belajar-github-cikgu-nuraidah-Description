# Repository

## Maksud

Repository ialah tempat utama untuk menyimpan satu projek dalam GitHub.

## Fungsi

- Menyimpan fail projek
- Menyimpan folder
- Menyimpan nota
- Merekod perubahan
- Memudahkan perkongsian projek

## Analogi Mudah

Repository boleh diibaratkan seperti satu almari khas yang menyimpan semua bahan bagi satu projek.
